# Search preparation replay contract

A search mutation changes only the addressed search control; it cannot establish record identity, authorize writes, or bypass complete list discovery. The maintenance.5 report stopped before an exact item read, with a failed empty-model witness and unchanged raw counts of 2024; published count 2019 is a different, unproved count domain.

Failure cases, written before implementation:

1. A required invalidUIElement/cannotComplete/illegalArgument observation refuses that frame. It must never be reclassified as optional NoValue.
2. An incomplete earlier polling frame must not poison all later independently complete frames. Conversely, a prior request incomplete flag must remain preserved outside an independent discovery scope.
3. Acceptance requires two consecutive complete frames; an incomplete frame, mismatched query/category, changed owner, or changed raw row generation resets the pair.
4. The impossible sentinel needs zero raw rows in both complete frames, and the category and owner must still match. Visible search text alone cannot prove model submission.
5. Target results require bounded nonempty rows, complete labels with the exact requested title present, identical labels in both frames, and owner/category/query proof. A zero target list does not prove item absence.
6. Clearing search needs a stable pair of complete empty-query frames, the same requested category, and raw count restoration evidence. Only a separately complete cached raw index count shares the AXRows domain. Published sidebar entry counts cannot substitute for it or be normalized by a guessed header offset.
7. Equal raw counts without a known complete raw cache remain unverified. A larger restored raw model is accepted only with unchanged owner, empty query, and confirmed category in both complete frames, preserving the existing restoration witness.
8. Diagnostics contain fixed stages, counts, complete/query/category/owner Booleans, optional bounded published counts and per-phase native error codes. They contain no labels, queries, usernames, sites, note bodies or credentials.
9. No new full-table scan is added for diagnosis. Errors remain recorded, required observations remain fail closed, and actual item uniqueness and deletion protections remain unchanged.

`tests/e2e_native_search_preparation.py` invokes the native `--search-replay-test` real entry before AppKit/Apple inspection. It feeds deterministic structural frames through the same independent discovery scope and consecutive-frame reducer used by actual search polling. Every run stores the exact command, helper hash and result. The isolated contract proves the code's state lifecycle and count-domain rules; it is not Apple acceptance.

## Empty-query zero-model recovery

The same-session deletion follow-up observed empty query, selected All, raw rows 0, published active count 2018 and no AX errors. This is not a proved empty library and must never reach complete-index absence authorization just because the visible search text is empty. The change must preserve a normal first complete nonempty All list with no cache and an independently proved empty raw cache. An empty cached list contradicted by a positive published count must hold.

Clear uses the existing addressed SelectedText replacement with empty text when independently complete range/text support is available, without AXValue, focus, events or activation. Setter/value success is not model success: the same two complete empty-query/category/owner frames plus raw count increase or separately complete raw cache must still pass. A failed or unchanged zero model holds; no sentinel retry loop. Only a proved unsupported SelectedText capability may retain the existing addressed Cancel route, with identical model proof. An attempted/refused/ambiguous SelectedText edit does not fall back to another submission.

## Deleted-body verification frames

A unique deleted row is not complete body proof. Each independent frame must bind the single selected row to the indexed exact identity, discover the complete detail values, compare the whole note to the expected note, and find exactly one ordinary recovery button. Invalid/stale/incomplete observations reset the consecutive pair. Two adjacent complete matching frames are required; a retained incomplete flag from a prior frame cannot poison a later complete pair. Safe diagnostics expose only selected_exact/title_matches/note_matches/recovery_unique/frame_complete and observed frame count. No recovery or deletion action is executed by this verifier.
