# Readonly notes-editor probe failure specification

This specification precedes implementation. Probe is diagnostic only, restricted to the existing synthetic fixtures; it never authorizes mutation or global uniqueness. Real Apple execution belongs to the root agent.

1. Missing/partial expected canonical state, missing `synthetic_only:true`, a non-synthetic title or note marker, a real username/domain, a nonempty password, or unexpected extra fields refuses before opening an editor. Fixture title/native title start with `apw API 测试`, notes contain `APW_EXCHANGE_SYNTHETIC_V1`, account is empty or ends `.invalid`, and sites are empty or use `.invalid` hosts.
2. An unavailable, locked, incomplete, or pre-existing user editor holds. Do not activate, open a new window, edit search text, change focus, or inject events to make the default probe run. The explicit foreground-focus diagnostic exception below is the only focus setter scope.
3. Current list must have 1–100 rows and two independently complete stable observations of its search value and every row label. Exact title/account match must be unique within that cohort. Empty account is confirmed by the complete editor state, not inferred from a missing row label. A filtered cohort never proves whole-library uniqueness.
4. Bind the current matching row and selected detail using existing read guards. A stale row, changed query/cohort, ambiguous detail/Edit button, incomplete opening, wrong full preimage, editable unmodeled verification seed, or owner change holds. The probe cannot cancel somebody else's pre-existing editor.
5. Two independent complete editor states must equal expected before notes capability diagnosis. Diagnose the exact NotesField and only its bounded descendants: standard roles/actions, attribute settable raw codes/booleans, same-PID/ancestor/identity flags, and equality booleans. No note/credential values or arbitrary captions/identifiers may enter output.
6. Capability absence is a valid diagnostic result; stale/transient responses, malformed structures, unstable frames, or a truncated descendant tree are incomplete and hold. No NotesField data attribute setter, AXConfirm, Save/Done, or import/export action is permitted. The default probe never sets focus; an explicit foreground-focus diagnostic may attempt only AXFocused under clause 13.
7. First Cancel must be exact, owned, and preserve all editable fields; the list must independently reappear. Rebind the same stable cohort, reopen the exact synthetic record, verify the complete canonical original state again, and Cancel a second time. Any cancellation, readback, or preservation failure holds and must never return `probed:true`.
8. Cohort labels may temporarily satisfy the existing `read()` selection interface, but must never be installed as an active/deleted full-library index or used to authorize a later write/delete. Invalidate temporary binding on all returns. No journal changes are allowed.
9. Success outputs only safe diagnosis and fixed flags: `probed:true`, `synthetic_only:true`, `mutation_authorized:false`, `current_cohort_only:true`, `credentials_changed:0`, `journal_modified:false`, `app_activated:false`, and `foreground_focus` equal to the requested Boolean (default false). No canonical snapshot or secret plaintext is returned.
10. Optional `AXFocusedUIElement` diagnosis reads only the verified target application element. A matching editable endpoint requires successful fresh copy/PID/role reads and a complete bounded parent chain to the unique current NotesField. An unavailable/foreign/stale/unbound/unknown object yields false, never a global focus setter or input permission. Output is only raw code, same-PID/matching booleans, and a fixed role enum.
11. A complete returned NativeRead is registered as this request's owned editor before canonical snapshot construction, so a snapshot failure cannot orphan a proven readonly editor. An incomplete/absent NativeRead cannot be registered from guessed fields.
12. A read failure may attempt exactly one expected-state recovery only if an independently complete editor-open observation occurred during this exact read, the original foreground and keyboard owners are unchanged, the lease is still valid, and expected is complete. Reuse the existing recovery's two complete exact canonical comparisons before Cancel. A partial/unobserved opening, a pre-existing user editor, foreign owner, changed state, editable unmodeled seed, or failed Cancel cannot justify closure; report `maintenance_editor_requires_review` and never blindly retry cleanup. A complete list observation proving no editor needs no recovery. Failure recovery cannot return `probed:true`.

13. Optional `foreground_focus` is absent/false by default and must be a JSON Boolean; numeric/string coercion is refused. Explicit true requires the original NSWorkspace foreground PID already equal Passwords before any editor opens. A known different system-wide keyboard PID refuses; nil is not evidence of another PID and is allowed only with positive target-app internal focus proof: successful complete copy/PID/known-role observation and complete bounded ancestry into the unique verified standard window. The original frontmost owner must remain Passwords through this entire diagnostic. No activation, raise, query change, event injection, new window, credential/notes value change, or global setter relaxation is permitted.
14. The independent foreground-focus primitive requires this request's owned synthetic editor, two complete canonical frames equal the full expected state and raw fields, and one current same-PID NotesField with exact identifier and editable text role. Each unique identifier/role/PID target discovery is independently complete; a partial scan cannot hide a second note or substitute a stale reference. Its AXFocused settable query must succeed and report true; an unsupported/stale/incomplete query holds without a setter. At most one raw AXFocused=true attempt is permitted. This narrow primitive must not route through or weaken the globally prohibited generic focus setter.
15. A successful focus setter is insufficient: a fresh complete target-app focusedUIElement observation must be same-PID and the exact current NotesField or a legitimate editable descendant whose bounded parent chain reaches that NotesField. Two complete unchanged canonical/raw-state frames and stable exact current note identity must still agree. A foreign/unbound/window focus, owner change, changed state, unsupported setter, or incomplete post-observation holds. No fallback or retry setter is allowed.
16. Continue capability diagnosis and both existing Cancel/preservation gates after verified focus. Safe focus diagnostics are only `focus_requested`, `focus_settable`, `focus_verified` Booleans and `focus_set_code` integer (if attempted). Foreground-only success never grants mutation authorization; cancellation/readback failures still cannot return `probed:true`.

17. Probe error cleanup may not reuse a NativeRead's cached websites/sharing/OTP/passkey together with equal raw text fields. Only this request's registered complete owned editor has a probe cleanup preimage. Error recovery compares two new complete canonical states to expected and both raw field frames to the registered original fields, before one exact Cancel. A changed site label with unchanged empty WebsiteField, changed sharing/OTP/passkey, staged field change, incomplete frame, or owner change holds and leaves the editor for review. Do not retry a failed guarded cleanup from a later generic catch or request. Default and foreground-focus probes share this protection; unrelated operations keep their existing paths.

Isolated verification: the real helper `--policy-test` entry runs before AppKit initialization. Policy cases must cover each refusal above that can be modeled without an actual Apple UI. The stored E2E report contains its absolute rerunnable command. Isolated success does not claim real Apple probe success.
